# Тестирование API в Postman для интернет-магазина

 В этом разделе — результаты тестирования REST API интернет-магазина: тест-кейсы, найденные баги и коллекция запросов.

---

## 📋 [Тест-кейсы для API](https://docs.google.com/spreadsheets/d/16FPndWr6k8YaZ06aKOZDUiVsvCkqhETpHeR95yF76wk/edit?gid=0#gid=0)
 
 В тест-кейсах описаны шаги, тестовые данные и ожидаемые результаты для каждого эндпоинта.

## 🐞 [Баг-репорты](https://drive.google.com/drive/folders/1u1pT-HVmjmHPluhcT7d8qGLFoGUiEe0L)

 Каждый баг содержит:
- Шаги воспроизведения
- Фактический и ожидаемый результат
- Скриншоты ответов API

## 📮 [Postman коллекция](./postman-collection/store_api_collection)

 В коллекции собраны запросы ко всем протестированным эндпоинтам интернет-магазина: продукты, пользователи, корзина, заказы, оплата.
